# Willow Glade tree materials

Original materials generated with the built-in `image_gen` tool using the
`imagegen` skill. PNG files retain the generated resolution and alpha channel.
The foliage is mapped onto curved, intersecting clusters in a 3D crown; the bark
is mapped around curved trunks and branches. No whole-tree sprite is used.

## Foliage

File: [foliage-cluster-v1.png](foliage-cluster-v1.png), 1484 × 1060, RGBA.

Prompt:

> Use case: stylized-concept. Asset type: transparent foliage texture for a polished hand-painted 3D cozy woodland game, NOT a whole tree or scene. Create ONE isolated dense broadleaf oak foliage clump on genuine transparent background. A naturally irregular oval mound, about 1.4 times as wide as tall, made of roughly 90-140 SMALL overlapping rounded oval oak/hornbeam leaves on tiny barely visible twigs. The clump has volume: dark forest teal-green recessed leaf pockets underneath, rich moss green midtones, delicate muted yellow-green new leaves along the upper silhouette. Organic rounded slightly scalloped leaf edges, subtle curved veins and soft painterly brushwork. Art direction: premium lush storybook woodland, carefully painted game foliage with convincing natural structure, crisp individual organic leaf silhouettes, no polygon or origami look. Viewed roughly front-on with a slight top view so it can be used on 3D foliage cards. Diffuse neutral daylight, gentle ambient occlusion inside the clump, NO cast shadow, NO bright white highlight. Fill the central 85% of a square canvas with comfortable fully transparent margin on all sides. Irregular silhouette with transparent gaps BETWEEN some leaves, no rectangular background, no grass, no trunk, no ground, no flowers, no fruit, no decoration, no text, no border, no sheet of separate disconnected items. This is a single coherent leafy branch cluster. Render with real alpha transparency.

## Bark

File: [oak-bark-v1.png](oak-bark-v1.png), 1254 × 1254, RGB.

Prompt:

> Use case: stylized-concept. Asset type: seamless bark albedo texture for a premium hand-painted cozy woodland 3D tree. Create a square flat surface texture of old oak bark, filling the entire image edge to edge. Vertical flowing bark ridges, fine irregular grain, deeply recessed narrow grooves, tiny naturally broken cracks, subtle cool olive moss staining only in occasional recesses. Warm desaturated walnut brown and gray brown with softly painted lighter edges. Refined painterly realism suitable for a richly illustrated fantasy woodland, detailed and tactile but not photographic. All grooves run generally VERTICALLY. Orthographic straight-on flat material swatch, soft even diffuse illumination, no directional cast shadow, no perspective, no tree silhouette, no branch, no ground, no objects, no text. Seamless tiling on all edges, no border, no background. Avoid large repeating straight stripes, polygon facets, oversaturated orange, thick black outlines or graphic stylization.
