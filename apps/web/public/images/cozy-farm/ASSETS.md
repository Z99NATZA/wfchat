# Cozy Farm generated assets

These original transparent PNGs were created with the built-in image_gen tool for this project. They are independent sprite atlases, not backgrounds. Original alpha is preserved. Environment frames are measured in art.ts; all runtime textures are normalized once to two texels per world pixel and rendered with nearest filtering. Character/crop sheets use four columns and two rows. Source sheets are not promised to be exact pixel-perfect production animation; the walking poses are limited.
