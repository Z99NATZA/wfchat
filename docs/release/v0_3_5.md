# v0.3.5 - Aiko Cafe Realtime Efficiency And Production Hardening

Release date: 2026-08-12

This patch release reduces Aiko Cafe realtime traffic, isolates slow
connections, and bounds production room and socket growth.

## Realtime Efficiency And Recovery

- Idle players send no movement traffic. Movement transitions remain immediate,
  while continuous movement and room movement batches are capped at 10 updates
  per second.
- Movement uses compact latest-value batches with a shared monotonic revision.
  Static map data is sent on `welcome`; reliable-channel lag closes with code
  `1013` so reconnect can obtain a complete fresh state.
- Cafe rooms preserve authoritative player work across overlapping reconnects.

## Production Boundaries

- Active sockets default to 2 per session, 32 per resolved IP, and 512 per API
  process. Actual room creation defaults to 5 per session, 30 per resolved IP,
  and 300 per process in the same 10-minute window. Resolved IPs use the
  trusted-proxy boundary, and rejections return `429`.
- WebSocket frames and assembled messages are limited to 16 KiB; oversized
  connections close with code `1009`.
- Never-joined rooms expire after 10 minutes. Empty rooms retain reconnect state
  for 2 minutes without a movement tick, with cleanup every 30 seconds.
- Aggregate Cafe room, socket, message, rejection, lag, and outgoing-byte
  signals are emitted every 60 seconds without logging individual movement.

## Upgrade Notes

- Deploy the Web and API together because the internal Cafe WebSocket movement
  protocol changed.
- All new Cafe limits have production-safe defaults, so existing deployments do
  not need additional environment values. Optional overrides are documented in
  [Backend architecture](../backend-architecture.md).
- CI now verifies real Cafe room creation, WebSocket welcome, and reconnect after
  reload through the Web, API, and PostgreSQL stack.

See [Aiko Cafe](../aiko-cafe.md), [Backend architecture](../backend-architecture.md),
and [Continuous integration](../ci.md) for current behavior and operating
details.
