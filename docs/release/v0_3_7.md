# v0.3.7 - Account Privacy And Cafe Avatars

Release date: 2026-08-28

This release adds permanent account deletion, a public Privacy Policy, and
selectable Aiko Cafe player avatars.

## Account Deletion

- Google users can permanently delete their account from Profile. This removes
  their profile, chats, attachments, learned context, synced data, and Cafe
  progress, then returns the browser to a new Guest.
- Browser Chat and Sync caches are cleared, while the device theme, font, and
  language remain. File cleanup continues automatically when an attachment
  cannot be removed immediately.
- Deleting and signing up again does not reset the current day's chat
  allowance. Security logs do not include private content or identity values.

## Public Privacy Policy

- `/privacy` explains WFChat's current data handling in Thai and English. It is
  public and does not start a user session.
- The policy is linked beside Google Login and at the bottom of Profile, so it
  remains easy to find before and after login.

## Aiko Cafe Avatars

- Players can choose the boy or girl avatar from the wardrobe. The selection is
  saved, carries over on Google Login, and appears to other room members.
- Both avatars now have complete four-direction animation. The girl uses the
  new long-haired pink design, and updated artwork refreshes without stale
  browser or game cache.

## Upgrade Notes

- Run the normal database migrations. Existing Cafe loadouts default to the boy
  avatar.
- Rebuild the API and Web together. No new environment value is required.
